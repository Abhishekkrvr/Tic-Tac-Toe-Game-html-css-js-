# Tic Tac Toe 🎮

A simple 2-player Tic Tac Toe game made with HTML, CSS, and JavaScript.

## Features

- X vs O turn-based game
- Win and draw detection
- Restart button
- Clean and minimal UI

## How to Play

Open `index.html` in any browser and start playing.
